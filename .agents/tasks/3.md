## Key Decisions
- 사용자 의도는 “최신 release 번호”보다 실제 재생 가능성. release1.18.2의 재현 가능한 API400을 해결한 공식 upstream 변경을 사용하며 움직이는 main/SNAPSHOT 대신 timestamp까지 고정.
- Android VR을 제거하면 현재 응답에서 재생목록을 로드하지 못함을 관찰하여 메타데이터 전용으로 분리. 새 임의 fallback/영상별 special case를 추가하지 않음.
- 별도 서버·OAuth/poToken/remote cipher·yt-dlp/Deno 실행 파일은 도입하지 않음. 비공개/계정/지역/IP 제한 우회를 보장하지 않음.
- 최신 `~/.omp/agent/RULES.md` 확인. 모든 새 commit author/committer는 `kdm1jkm-agent <agent@kdm1jkm.com>`으로 지정하고 네 identity 환경변수를 commit 프로세스에만 일치시킴. Git 설정과 gh 인증/credential store는 변경하지 않음. `.env`나 토큰을 읽거나 출력하지 않음.

## Unresolved Issues & Handoff
- 기존 권한403·충돌·실제 오디오 프레임 미제공은 해소됨. Revision2의 로컬 동작·기본 CI·독립 코드 승인 증거를 확보했으며 최종 인계 문서 head CI를 확인한 뒤 PR에 PASS 판정을 기록. 자동 merge하지 않음.
- 새 head 독립 리뷰, CI URL/결과, PASS 여부와 남은 제한은 PR 최신 댓글을 진실의 기준으로 확인.
- 과거 dev 병합에서 상속한 promotion 명령의 `gh --slurp`/`--jq` 조합은 로컬 gh가 거부함. 실제 jq guard는 live 단일페이지 payload에서 정상/실패/누락/폐기된 이름 판정을 검증했으나 promotion 전체/페이지네이션·태그 부작용은 미실행. 이번 playback 수정에서 무관한 명령을 변경하지 않음.
